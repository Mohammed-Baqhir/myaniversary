# Our Two Years — Anniversary Website

A responsive React + Vite anniversary gift website.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`

## Build
Run `npm run build`. Vite creates the production site in `dist/`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import that repository in Vercel.
3. Framework preset: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

The photos are stored locally in `public/images`, so they are included in deployment.
